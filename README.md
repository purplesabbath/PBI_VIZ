# 区间直方图 Interval Histogram · Power BI 自定义视觉对象

用于衡量指标"区间分布"的直方图。带统计常量参考线、KDE 密度曲线、可配置统计量图例。

- 打包产物：`dist/intervalHistogram4B7E1C2D9A5F4E8B8C3D6A1F2E9B7C40.1.0.0.0.pbiviz`
- API 版本：`5.9.0`（Power BI Desktop 2023 及以后版本）
- 语言：TypeScript + 原生 SVG（无第三方图表库，包体很小）

---

## 一、安装

1. 打开 Power BI Desktop。
2. 右侧「可视化」窗格 → 底部的 `…`（更多视觉对象）→ **从文件导入视觉对象**。
3. 选择 `.pbiviz` 文件，确认导入。视觉对象会出现在可视化窗格中（图标为柱状图）。
4. 导入时若提示"此视觉对象不是经过认证的视觉对象"，选择**仍然导入**即可（自建视觉对象都不会有微软认证）。

## 二、数据字段

| 字段槽 | 接受的类型 | 含义 |
| --- | --- | --- |
| **类别** | 文本、日期（也接受其他非数值列） | 每一行 = 分布中的一个样本（一个观测值） |
| **值** | 数值列 **或** 度量值 | 参与统计与分箱的数值 |

> 关键点：直方图需要"很多个样本"，所以**必须放类别字段**（例如订单号、日期、产品名），否则 Power BI 会把整列聚合成一行，直方图无从统计。视觉对象检测到这种情况会给出提示。

## 三、格式面板（与需求逐条对应）

### 1. 类别轴 / 值槽 ✔
类别槽接受文本或日期字段；值槽接受数值字段或度量值（`GroupingOrMeasure`）。

### 2. 分箱与柱形 ✔
| 设置 | 说明 |
| --- | --- |
| 区间数量 | 滑块，2–200，默认 **30** |
| 填充颜色 | 不修改时跟随报表主题色 |
| 透明度 | 0–100% |
| 柱间距 | 0–0.8（占单个区间宽度的比例） |
| 圆角半径 | 0–20 px |
| 显示描边 / 描边颜色 | 柱形能否加边框 |

分箱算法：等宽分箱，区间 **左闭右开** `[a, b)`，最后一个区间包含最大值。

### 3. 常量参考线（9 条）✔
每条线独立可调：**开/关（分组标题上的开关）**、颜色、粗细（0.5–8 px）、线型（实线/虚线/点线/点划线）、是否显示"名称 + 数值"标签。

| 分组 | 位置 |
| --- | --- |
| 均值 | x = 均值 |
| 中位数 | x = 中位数 |
| 标准差 σ | x = σ（σ 本身作为一个数值位置） |
| 均值 ±1σ | x = 均值 ± σ |
| 均值 ±2σ | x = 均值 ± 2σ（**附加**，默认关闭） |
| 均值 ±3σ | x = 均值 ± 3σ |

标签会自动分道避让：多条线挨得近时标签会自动下移一行，并且会主动躲开统计量图例框；线超出数据范围时不绘制。

### 4. KDE 密度曲线 ✔
| 设置 | 说明 |
| --- | --- |
| 显示曲线 | 分组开关 |
| 颜色 / 粗细 / 线型 | 独立可调 |
| 带宽倍数 | 1 = 自动（Silverman 经验法则）；<1 更贴合数据，>1 更平滑，范围 0.1–4 |
| 曲线下方填充 / 填充透明度 | 面积填充 |

注：直方图的纵轴是**频数**，所以 KDE 已按 `密度 × 样本数 × 区间宽度` 换算到同一条纵轴上，两者可以直接对比。

### 5. 统计量图例 ✔
- 位置：右上/左上/右下/左下
- 列数 1–3、字号、小数位 0–6、文字颜色、背景色 + 背景透明度、边框开关 + 边框颜色
- 可选统计量（共 15 项，各自独立开关）：
  均值、中位数、标准差、方差、计数、最大值、最小值、CV、VSF、偏度、峰度、25% 分位、75% 分位、90% 分位、10% 分位

### 6. 坐标轴与标签 ✔
| 设置 | 说明 |
| --- | --- |
| 显示 X 轴 / Y 轴 | 开关 |
| X 轴标题 / Y 轴标题 | 文本可改，默认「区间」「计数」，可单独关闭 |
| X 轴刻度角度 | 水平 0° / 倾斜 45° / 垂直 90° |
| 刻度字号 / 标题字号 | 6–24 / 6–28 |
| 标签颜色 / 轴线颜色 | 颜色选择器 |
| 显示横向网格线 / 网格线颜色 | 开关 + 颜色 |
| Y 轴从 0 开始 | 关闭后纵轴从最小频数附近开始，便于观察矮柱 |

## 四、交互

- **悬停**：显示区间、计数、占比的提示框，同时高亮该柱子。
- **单击柱子**：交叉筛选/高亮到该区间对应的行（其他视觉对象联动）。
- **Ctrl / Shift + 单击**：多选多个区间。
- **再次单击同一柱子 / 单击空白处**：取消选择。
- **被其他视觉对象筛选时**：本视觉会以"淡化背景 + 高饱和前景"的方式显示被选中的那部分样本（Power BI highlight 协议）。

## 五、统计量口径

| 指标 | 公式 / 口径 |
| --- | --- |
| 均值 | 算术平均 |
| 中位数 | 线性插值分位数（等同 Excel `PERCENTILE.INC`） |
| 方差 / 标准差 | **样本**口径（除以 n−1） |
| 偏度 | 与 Excel `SKEW` 一致（调整 Fisher-Pearson） |
| 峰度 | **超额峰度**，与 Excel `KURT` 一致（正态分布 = 0） |
| CV | 标准差 ÷ 均值 |
| **VSF** | **标准差 ÷ 中位数**（稳健变异系数，均值接近 0 时比 CV 更可用） |
| 分位数 | 线性插值，等同 Excel `PERCENTILE.INC` |

> VSF 没有统一的教科书定义。这里采用"标准差 ÷ 中位数"。如果你的业务口径不同（例如 极差÷均值、σ÷P75 等），只需改 `src/stats.ts` 中 `computeStats` 里 `vsf: ...` 那一行，图例与常量线会同步生效。

## 六、从源码构建

```bash
npm install
npx pbiviz package          # 产物在 dist/*.pbiviz
```

> `pbiviz package` 会报一句 "Certificate verification error / Create certificate error"——那是本地调试服务器要用的证书，**不影响打包**，可以忽略。

### 本地预览（不装 Power BI Desktop 也能看效果）

```bash
node tools/make-icon.js            # 重新生成图标
npx pbiviz package --resources --no-minify
cp dist/resources/visual.prod.js dist/resources/visual.prod.css tools/
# 用浏览器打开 tools/preview.html
```

`tools/preview.html` 用一套模拟的 Power BI Host 渲染了三个样例（默认设置 / 8 区间全统计量 / 小尺寸），并自带 6 项交互自测（tooltip、高亮、选择、清除、无类别字段兜底等）。

## 七、已知限制

1. **必须放类别字段**：只放度量值时 Power BI 只返回一行聚合结果，视觉对象会提示补充类别。
2. 分箱固定为等宽分箱，暂不支持自定义分箱边界 / 对数坐标。
3. 常量参考线超出数据范围时不显示（避免画出图外）。
4. 未实现自定义右键菜单与高对比度模式适配（不影响使用）。
5. 视觉对象未做本地化（界面为中文），如需英文/多语言版本需增加 `stringResources`。

```
├── style/visual.less

│   ├── preview.html       # 本地预览 + 交互自测

```
